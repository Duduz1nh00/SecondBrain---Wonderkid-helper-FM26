# Caderno Temático: Categorias de Base no FM26

## Contexto e Objetivos

Sou um entusiasta de análise tática e gosto de entender o futebol para além do campo e bola. Analisar os dados de uma partida é interessante para entender por que o Time A ou B jogou bem ou mal. Pensando nisso, escolhi me aprofundar nas **Categorias de Base no Football Manager 2026**. 

Meu principal desafio é entender melhor como funciona a formação de novos atletas e descobrir o que se deve levar em consideração além do talento bruto (se ele é bom ou não). Com este projeto, meu objetivo é auxiliar todos aqueles que desejam analisar e compreender melhor o futebol virtual e real.
